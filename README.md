# 汇编学习台 · C ⇄ x86-64 双向对照

一个用来学汇编的工具：写 C 就能看到等价的 x86-64 汇编，读汇编就能还原出伪 C，配逐行讲解、内存动画、问题检查和自动补全。
所有计算（C 编译器、汇编器、模拟器、反编译器）都是自己实现的，不依赖任何第三方库，也不联网。

---

## 一、怎么用

### 方式 1：双击 exe（推荐）

```
dist\汇编学习台.exe
```

- 双击后会用一个**独立窗口**打开（浏览器 app 模式，没有地址栏和标签页），看起来就是一个普通桌面软件。
- 双击**不会弹黑色命令行窗口**（exe 已改成窗口子系统），出错时会弹系统提示框，并写 `asm-studio-error.log`。
- 整个程序（前端 + 后端接口 + Node 运行时）都打包在这**一个 exe** 里，不需要装 Node，不需要联网，可以随便拷给别人。
- 关掉窗口，后台服务会在 3 秒内退出（页面关窗时通知后端；万一通知丢了，90 秒无心跳也会退）。
- **重复双击不会开出两个服务**：检测到已有实例就直接复用它的窗口。
- 每次启动都用全新的浏览器 profile，避免上次非正常退出留下的锁让窗口"一闪就没"。

命令行参数：

| 参数 | 作用 |
| --- | --- |
| `--port N` | 指定端口，默认从 41730 起找一个没被占用的 |
| `--host 0.0.0.0` | 让同一局域网的人也能访问（会打印出局域网地址） |
| `--no-window` | 只启动服务，不弹窗口（部署用） |
| `--quiet` | 不打印日志 |
| `--help` | 看帮助 |

**分享给同事**：

```bat
汇编学习台.exe --host 0.0.0.0 --port 8080 --no-window
```

然后同事用浏览器打开 `http://你的IP:8080` 就能用，大家各用各的页面，互不干扰。

### 方式 2：直接开网页（离线）

双击 `index.html` 即可，所有计算都在浏览器本地完成，功能和 exe 完全一样，只是不经过后端接口。
（用 `file://` 打开时右上角会显示「本地」，用后端托管时显示「服务端」。）

## 二、界面与功能

```
┌──────────────┬──────────────┬──────────────┬────────────┐
│ 汇编（最宽） │  C 源码      │  分析        │  AI 解读   │
│ 左侧         │  右侧        │  逐行/总体   │  独立栏    │
│              │              │  指令速查    │            │
│              │              │  问题        │            │
└──────────────┴──────────────┴──────────────┴────────────┘
                 底部：内存可视化 + 程序输出
```

- **C → 汇编**：左边写 C，点「编译并加载」（或 Ctrl + Enter），左边生成等价汇编。生成的汇编可以直接改，改完自动重新分析。
- **汇编 → C**：直接在汇编框里写（或粘贴老师的代码），右边实时给出还原出来的伪 C。
- **逐行分析**：点任意一行汇编，说明这一行在做什么、动了哪块内存、标志位怎么变；底部内存视图同时"执行到这一行"，箭头就是数据流向。
- **单步 / 连续执行**：底部按钮，寄存器和栈内存实时更新，程序输出在右侧控制台。
- **问题面板**：错误 / 警告 / 提示三级，带行号、代码片段和"怎么改"，点一下跳到那一行，出问题的行号会标红。
- **指令速查**：97 条指令的中文说明、示例、副作用。
- **AI 解读**：默认本地引擎（读语法树 + 真实运行结果），也可以填 OpenAI 兼容接口用大模型再讲一遍（密钥只存本机）。

### 快捷键

| 键 | 作用 |
| --- | --- |
| 行末 **回车** | 汇编框：换行并弹出**整行写法**补全 |
| **↑ / ↓** | 在补全列表里选 |
| **回车 / Tab** | 确认补全 |
| **Esc** | 关掉补全 |
| **Ctrl + 空格** | 手动唤出补全 |
| **Ctrl + Enter** | 编译并加载 |
| **Tab** | 缩进 4 个空格 |

补全给的是**能直接用的整行**，比如 `mov eax, DWORD PTR [rbp-4]`、`addsd xmm0, QWORD PTR [rbp-8]`、`jmp .L2`，而不只是一个操作码。
C 框只补 C 自己的东西（关键字、printf/puts/putchar/exit 的完整写法、for/if/while 骨架、已声明的变量），**不会插入任何汇编**。

## 三、支持范围

- **C 语言**：`int / long / short / char / float / double / void`，`unsigned / signed`（比较、除法、右移按无符号语义生成）；指针 `T*`、数组 `T[N]`、`struct`；`if-else / while / for / do-while / break / continue / return / switch-case-default`；算术、比较、逻辑、位运算、三目 `?:`、复合赋值、下标、成员 `.` 与 `->`、强制类型转换、`sizeof`；自定义函数（整型/指针参数最多 6 个，浮点最多 8 个）；全局变量、结构体数组、二维数组、`char s[]="..."`。
- **内置函数**：`printf`（`%d %i %u %s %c %x %X %o %p %ld %f %.2f %e %E %g %G`、宽度与精度、`%-5d`、`%05d`、`%%`；参数个数不限）、`puts`、`putchar`、`exit`。
- **汇编**：Intel 语法 97 条指令，支持 `QWORD PTR [rbp-8]`、`[rbp+rax*4+8]`、`.LC0`、`.LC0[rip]`、`.section .rodata` + `.string / .quad` 等。
- **不支持的**：goto、枚举、联合体、函数指针、结构体按值传参（请传指针）。这是教学模拟器：地址、位宽、标志位、IEEE-754 都按真实规则算，但不做真实系统调用和内存保护。

## 四、后端接口

页面由后端托管时，编译走服务端；也可以直接当接口用：

```bash
curl -s http://127.0.0.1:41730/api/health

# C → 汇编
curl -s -X POST http://127.0.0.1:41730/api/compile \
  -H "Content-Type: application/json" \
  -d '{"code":"int main(){ printf(\"%d\\n\", 6*7); return 0; }"}'

# 汇编 → 伪 C（同时返回问题列表）
curl -s -X POST http://127.0.0.1:41730/api/decompile \
  -H "Content-Type: application/json" \
  -d '{"asm":"main:\n push rbp\n mov rbp, rsp\n mov eax, 7\n leave\n ret"}'

# 直接跑出程序输出
curl -s -X POST http://127.0.0.1:41730/api/run \
  -H "Content-Type: application/json" \
  -d '{"code":"int main(){ printf(\"%d\\n\", 6*7); return 0; }"}'
# → {"ok":true,"output":"42\n","steps":20,"halted":true}

# 只做代码检查
curl -s -X POST http://127.0.0.1:41730/api/check \
  -H "Content-Type: application/json" \
  -d '{"asm":"main:\n movv eax, 5"}'
```

所有接口都是 `POST + JSON`，允许跨域（`Access-Control-Allow-Origin: *`）。

另外还有两个内部接口，前端窗口靠它们和进程"对表"：

| 接口 | 作用 |
| --- | --- |
| `GET /api/ping` | 页面每 15 秒报活一次，后端用它判断窗口还在不在 |
| `POST /api/bye` | 关窗时页面用 `sendBeacon` 通知后端退出；3 秒内若有新心跳（说明是刷新）就撤销 |

## 六、自己打包 / 开发

```bash
# 开发：本地起服务（改完刷新页面即可）
node build/server.js --port 41730

# 打包成单文件 exe（需要本机装了 Node 18+ 和 Python 3）
python build/make-exe.py
#   或双击  打包.bat
```

打包原理（Node 官方 SEA，Single Executable Application）：

1. `build/make-bundle.js` 把 `js/` 里的计算模块和服务端合成一个脚本；
2. `node --experimental-sea-config` 生成 blob（含主脚本 + 前端静态资源）；
3. 复制 `node.exe`，把熔断开关 `NODE_SEA_FUSE_...:0` 改成 `:1`；
4. 用 Win32 `UpdateResource` 把 blob 写成 exe 的 **`RT_RCDATA` / `NODE_SEA_BLOB`** 资源
   （类型必须是整数 `RT_RCDATA`，名称才是字符串 `NODE_SEA_BLOB`，两者都用字符串会直接崩）；
5. 改 PE 头 `Subsystem` 3 → 2，变成窗口程序：双击不再弹黑框；
6. 自检：真正启动 exe 并请求 `/api/health`，返回 `ok` 才算打包成功。

> 两个容易踩的坑，都已经处理：<br>
> · 浏览器把 `--app=url` 交给**已经在运行的实例**时，新进程会立刻退出。若把它当成"用户关窗"就会把刚起来的服务杀掉 —— 现在只有子进程存活超过 1.5 秒才把退出当作关窗。<br>
> · `sea.getAsset()` 不带编码参数时返回的是 `ArrayBuffer`（没有 `.length`），直接当 Buffer 用会得到空文件 —— 已统一转换。

跑测试：

```bash
node tests/run.js      # 全部 8 个测试文件
```

## 七、本次更新做了什么

| 要求 | 实现 |
| --- | --- |
| 汇编框放左侧并调大 | 网格改为 `1.42fr 1fr 1fr`，汇编栏在最左、最宽；宽屏时 AI 栏独立成第四栏 |
| C 框放右侧 | C 栏移到第二位，紧跟汇编栏 |
| 第 20 行开始行号错位 | **根因**：`pre` 末尾空行不生成行盒，高亮层 `scrollHeight` 比 textarea 少 20px，滚到底时 `scrollTop` 被钳住，导致整块行号错开一行。修法：空行补零宽字符让行盒数量完全一致，并让行号跟随代码层的真实 `scrollTop`。实测滚到底偏差 **0px** |
| C 端不插入汇编 | C 框补全只保留 C 关键字、内置函数、语句骨架、已声明变量 |
| 补全改为行末回车触发、给整行写法 | 汇编框：行末回车 → 换行缩进 → 弹出补全，每条都是**完整可用的一行**（60+ 条指令的具体写法表 + 按分类兜底）；↑↓ 选择、回车/Tab 确认、Esc 关闭、Ctrl+空格手动唤出 |
| 非示例代码也能互转 | 重写反编译器（函数切分、参数推断、类型推断、结构化、栈传参还原），新增 54 项回归断言覆盖手写汇编与 6 组往返 |
| 代码报错/错误提示系统 | 新增「问题」面板：错误/警告/提示三级 + 行号 + 代码片段 + 修复建议 + 点击跳行 + 行号标红；检查项含指令拼写、操作数个数、宽度不匹配、内存→内存、除零、`[rbp+8]`、栈平衡、调用对齐、只写不读变量等 |
| 前端 + 后端 + 可部署 | 新增零依赖 Node 后端（静态托管 + `/api/compile` `/api/decompile` `/api/run` `/api/check` `/api/health`），前端在线走服务端、离线自动退回本地；并打包成**单文件 exe**，也可 `--host 0.0.0.0` 给局域网用 |
| 顺带修的 | `printf` 栈传参改为一次性按 16 字节对齐开参数区（原实现奇数个栈参数时 `call` 前 rsp 未对齐，参数里再套函数调用会破坏 ABI） |
| 双击后窗口"一闪就没" | **根因**：浏览器 profile 目录里残留的锁文件让 Chrome 启动后立刻退出，而原逻辑把"浏览器进程退出"当成"用户关窗"，顺手把服务也杀了。修法：① 每次启动用全新的 profile（并按 pid 清理已死实例的残留目录）；② 关闭判断改为页面心跳（15 秒 ping）+ 关窗 `sendBeacon`，不再看浏览器进程；③ 收到关窗通知等 3 秒，期间有新心跳就撤销，所以**刷新页面不会把服务弄没** |
| 重复双击开出两个窗口 | 启动时先探测默认端口上是不是本程序，是就直接复用那个实例的窗口，第二份进程立刻退出 |
