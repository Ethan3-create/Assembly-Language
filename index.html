怎么用这个工具

      
    

    

      
1. 两种方向

      
C → 汇编：在左边写 C 代码，点「编译并加载」，中间会生成与之等价的 x86-64 汇编（未优化风格，和 GCC -O0 的结构一致）。生成的汇编可以直接改，改完自动重新分析。

      
汇编 → C：直接在中间写汇编（或粘贴老师给的代码），左边会实时给出还原出来的伪 C 代码，右边给出逐行解释与整体分析。

      
2. 自动补全怎么用

      
在汇编框里把光标放到某一行末尾，按回车就会弹出补全，给的是能直接用的整行写法（不只是指令名），例如 mov eax, DWORD PTR [rbp-4]、addsd xmm0, QWORD PTR [rbp-8]。用 ↑ ↓ 选，回车或 Tab 确认，Esc 关掉；也可以随时按 Ctrl + 空格 手动唤出。已经打了操作数时，补的是寄存器、内存写法或代码里已有的标签。

      
C 框只补 C 自己的东西（关键字、printf/puts/putchar/exit 的完整调用写法、for/if/while 骨架、已声明的变量），不会插入任何汇编。

      
3. 问题面板（报错提示）

      
右边「问题」标签页会把所有毛病分级列出来：错误（改不了就跑不了）、警告（很可能写错了）、提示（值得注意）。每条都带行号、出问题的代码片段和"怎么改"的建议，点一下就能跳到那一行，出问题的行号还会标红。检查内容包括：指令拼写、操作数个数、内存宽度与寄存器是否匹配、mov 内存→内存、除以 0、[rbp+8]（返回地址）、栈指针是否平衡、call 前 rsp 是否 16 字节对齐、变量声明了没用等。

      
4. 逐行分析

      
点中间任意一行汇编，右侧显示这一行在做什么、操作了哪块内存、标志位怎么变；同时底部内存视图会"执行到这一行"，黄色箭头就是这一行搬运数据的路径。

      
5. 单步与动画

      
底部「单步」每按一次执行一条指令，寄存器和栈内存的值会实时更新，橙色箭头表示数据的流向（内存→寄存器 是读，寄存器→内存 是写）。也可以点「连续执行」自动跑完。

      
6. AI 代码解读栏

      
最右边的「AI 代码解读」是一块独立分析栏（窄屏下点顶栏「AI 解读」滑出）。它默认用本地分析引擎：直接读语法树、指令流和真实运行结果，生成"这段代码在做什么"的说明、各变量最终的值、程序输出和需要注意的点，不需要联网。

      
如果填了 OpenAI 兼容接口（右上齿轮），还能点「AI 深度分析」让大模型再讲一遍。密钥只存在本机浏览器里。

      
7. 支持范围

      
C 语言：int / long / short / char / float / double / void，以及 unsigned / signed 前缀（unsigned 的比较、除法、右移都按无符号语义生成）；指针 T*、数组 T[N]、struct 结构体；if-else / while / for / do-while / break / continue / return；算术、比较、逻辑、位运算、三目 ?:、复合赋值、下标、成员 . 与 ->、类型转换、sizeof；以及自定义函数（整型/指针参数最多 6 个，浮点参数最多 8 个）。

      
内置函数：printf（支持 %d %i %u %s %c %x %X %o %p %ld %f %.2f %e %E %g %G 以及宽度、精度、%-5d、%05d、%%；参数个数不限，超过 5 个整数或 8 个浮点会自动按约定走栈传递）、puts、putchar、exit。

      
汇编指令（共 97 条，点任意一行都能看到讲解）：数据传送 mov / movzx / movsx / movsxd / lea / xchg / movd / movq / movaps / movups、栈 push / pop、算术 add / sub / adc / sbb / inc / dec / imul / idiv / div / neg / cdq / cqo / cdqe / cltq / cwd / cqto、逻辑 and / or / xor / not / cmp / test、移位 shl / sal / shr / sar、控制流 jmp / jcc / setcc / cmovcc / call / ret / leave / nop / hlt、浮点 SSE movsd / movss / addsd / subsd / mulsd / divsd / addss / subss / mulss / divss / sqrtsd / ucomisd / comisd / ucomiss / comiss / cvtsi2sd / cvtsi2ss / cvttsd2si / cvttss2si / cvtsd2ss / cvtss2sd / xorpd / xorps / pxor。

      
语法：Intel 语法，支持 QWORD PTR [rbp-8]、[rbp+rax*4+8]、.LC0 标签，以及 .section .rodata + .string / .quad 数据段。

      
其它能力：全局变量（带初值，放 .data 段）、switch / case / default、do-while、三目运算、结构体数组、二维数组、char 字符串数组。

      
这是一个教学模拟器：地址、寄存器宽度、标志位、IEEE-754 浮点都按真实 x86-64 规则计算，但不做真实的系统调用与内存保护。暂不支持：goto、枚举、联合体、函数指针、结构体传值（请传指针）。

      
8. 独立运行 / 分享给他人

      
方式一（推荐）：双击 dist\汇编学习台.exe，会开一个独立窗口，不需要装 Node、不需要联网。不会弹黑色命令行窗口；万一启动不了会弹系统提示框，并把细节写进同目录的 asm-studio-error.log。整个程序（含后端接口）都在这一个 exe 里，关掉窗口服务一起退出。

      
方式二：汇编学习台.exe --host 0.0.0.0 --port 8080 --no-window，让同一个局域网里的同事用浏览器打开 http://你的IP:8080。

      
页面由后端托管时，编译会走服务端接口（/api/compile、/api/decompile、/api/run、/api/check），右上角显示"服务端"；直接双击 index.html 打开则是纯离线模式，所有计算都在浏览器里完成，功能完全一样。

    

  






  

    

      
接入大模型（可选）

      
    

    

      
本地分析引擎不需要任何配置。想用大模型做更细的讲解时，填一个 OpenAI 兼容接口即可（OpenAI、DeepSeek、通义、本地 Ollama 的 /v1 都行）。

      
      
      
      
密钥只保存在本机浏览器的 localStorage，本工具不会把它发到别处。部分服务商不允许浏览器直连（CORS），若提示网络错误，请换用支持跨域的服务或本地 Ollama。
